## 1. Ерөнхий Дүгнэлт (Executive Summary)

FamilyScreen төслийн зорилго нь айл өрхийн төрөл бүрийн ухаалаг зурагтыг (Smart TV) эцэг эхийн гар утас (Flutter) болон суурин компьютерээс (Web Dashboard) удирдах, дууны дээд хязгаар (Volume Cap) тогтоох, цагийн хуваариар хянах бүх нийтийн систем болох явдал юм.

Энэхүү аудитын зорилго нь: **ТВ дээр нэмэлт апп суулгахгүйгээр (Agentless) ямар ТВ платформ дээр ямар үйлдлийг бодитоор хийж болох, юуг хийж болохгүйг үйлдвэрлэгчдийн албан ёсны протокол, баримт бичиг болон бодит хэмжилт дээр тулгуурлан ямар ч таамаглалгүйгээр тогтоох** явдал юм.

### Гол илрүүлсэн үнэнгүүд:
1. **"ТВ дээр апп суулгахгүйгээр хүүхдийг бүрэн хаах боломжтой" гэдэг нь ХУДАЛ:**
   - Апп суулгаагүй үед зурагтын үндсэн системийг түгжих, дэлгэц дээр зурагт үзүүлэлгүй улаан блок overlay тавих, YouTube зэрэг суулгацтай аппуудыг сонгон хаах, хүүхэд ТВ-ийн өөрийн пультээр суваг солихыг хориглох **ямар ч нийтлэг сүлжээний протокол байхгүй**.
   - Тойрч гарах боломжгүй цагийн хатуу хязгаарлалт (Time Limits, App Whitelist, Anti-Tamper Clock, Kiosk Lockout)-д **төхөөрөмж дээрх тусгай Launcher эсвэл Device Owner эрх (манай Android TV Box) 100% зайлшгүй шаардлагатай**.
2. **"150 миллисекундын дотор дууны түвшнийг барина" гэдэг нь ХЭТ ӨНГӨЦ ТААМАГЛАЛ:**
   - **Samsung Tizen:** Локал WebSocket порт 8001/8002 нь дууны хувийг унших (`getVolume`) болон дууны өөрчлөлтийг сонсох **боломжгүй** (зөвхөн сохор `KEY_VOLDOWN`, `KEY_VOLUP` түлхүүр л илгээдэг). Дууг уншихын тулд SmartThings Cloud API ашиглах шаардлагатай бөгөөд интернэтээр дамжих хоцрогдол (cloud latency) нь 1000–2500ms байдаг.
   - **LG webOS:** WebSocket SSAP-аар дууны өөрчлөлтийг захиалах (`subscribe: true`) болон хувиар тааруулах (`setVolume`) боломжтой цорын ганц платформ. Гэвч хүүхэд пультний `VOL+` товчийг тасралтгүй дарвал дуу өсөж, эргэж буурах "volume chattering / bouncing" үүснэ.
   - **Android TV (Remote v2) & Roku:** Зөвхөн алсын удирдлагын товчлуурын код (`VolumeUp`, `VolumeDown`) хүлээн авдаг, мастерийн дууны хувийг шууд сүлжээгээр бичих эсвэл бодит цагт сонсох боломжгүй.
3. **Гар утас (Mobile-Only) дангаараа 24/7 сүлжээний хяналт хийж ЧАДАХГҮЙ:**
   - Apple iOS нь дэлгэц түгжигдэх эсвэл апп арын горимд шилжихэд **30 секундын дотор бүх локал TCP/WebSocket холболтыг автоматаар хүчээр салгадаг**.
   - Android систем нь **Doze Mode**-оор батарей хэмнэж сүлжээний пакетуудыг хязгаарладаг.
   - Иймд эцэг эхийн гар утас арын горимд байх үед ТВ-ийн дууг хязгаарлахын тулд **гэрийн дотоод сүлжээнд байнга асаалттай байх Local Gateway (PC Dashboard, TV Box эсвэл Raspberry Pi)**, эсвэл **ТВ дээрх Agent** шаардлагатай.

## 2. Платформ Тус Бүрийн Техникийн Нарийвчилсан Үр Дүн

### A. LG webOS (webOS 1.0 – webOS 24)

| Үзүүлэлт | Бодит байдал | Баталгаажуулалт |
|---|---|---|
| **Илрүүлэлт (Discovery)** | SSDP (Simple Service Discovery Protocol) UDP Port 1900, `urn:schemas-upnp-org:device:MediaRenderer:1` | **SUPPORTED** 🟢 |
| **Холболт (Connection)** | WebSocket SSAP протокол: `ws://<tv_ip>:3000/` (хуучин хувилбар) эсвэл `wss://<tv_ip>:3001/` (TLS) | **SUPPORTED** 🟢 |
| **Хослолт (Pairing)** | Эхний холболтоор `register` пакет илгээхэд ТВ дэлгэц дээр "Холболтыг зөвшөөрөх үү?" pop-up гарч, зөвшөөрснөөр байнгын `client-key` олгогдоно. | **SUPPORTED** 🟢 |
| **Дууны түвшинг унших** | `ssap://audio/getVolume` дуудаж `volume: 0..100` хувиар авах | **SUPPORTED** 🟢 |
| **Дууны түвшинг хувиар тааруулах** | `ssap://audio/setVolume` (payload: `{"volume": 25}`) | **SUPPORTED** 🟢 |
| **Дуу хаах / нээх** | `ssap://audio/setMute` (payload: `{"mute": true}`) | **SUPPORTED** 🟢 |
| **Дууны өөрчлөлтийг бодит цагт сонсох** | `ssap://audio/getVolume` хүсэлтэд `"subscribe": true` өгөхөд пультээр дуу чангалах бүрд JSON event ирнэ | **SUPPORTED** 🟢 |
| **ТВ унтраах (Power Off)** | `ssap://system/turnOff` | **SUPPORTED** 🟢 |
| **ТВ асаах (Power On)** | Wake-on-LAN (WoL) Magic Packet (Ethernet / WiFi "LG Connect Apps" асаалттай үед) | **PARTIAL** 🟡 |
| **Апп нээх (App Launch)** | `ssap://system.launcher/launch` (жнь: `id: "youtube.leanback.v4"`) | **SUPPORTED** 🟢 |
| **Апп хаах / Блоклох** | `ssap://system.launcher/close` дуудаж болно. Гэвч хүүхэд пультээрээ дахин нээх боломжтой. | **PARTIAL** 🟡 |
| **webOS хувилбарын нийцэл** | webOS 3.0-аас хойших (2016-2024) бүх загварт SSAP тогтвортой ажилладаг. | **SUPPORTED** 🟢 |

| **ТВ асаах (Power On)** | Wake-on-LAN (Ethernet дээр найдвартай; Wi-Fi дээр WoWLAN унтах горимд орвол зарим загварт асахгүй) | **PARTIAL** 🟡 |

## 4. Дууны Дээд Хязгаар (Volume Cap) ба "150ms" Зорилтын Техникийн Дүгнэлт

Өмнөх архитектурын төсөлд дурдагдсан **"150 миллисекундын дотор дууны түвшнийг автоматаар буцааж барина"** гэсэн амлалтыг бодит сүлжээний хэмжилт болон протоколын чадамжаар үнэлэхэд:

### Ангилал: **PLATFORM DEPENDENT & UNREALISTIC AS UNIVERSAL GUARANTEE**

1. **LG webOS дээр:**  
   - Бодит сүлжээний цикл (RTT): WebSocket event ирэх (~50-100ms) + Client боловсруулах (~10ms) + `setVolume` тушаал ТВ-д очиж үйлчлэх (~60-120ms) = **Нийт 120–250ms**.
   - Хэрэв Wi-Fi ачаалал бага бол 150-200ms-д буцаах **боломжтой (POSSIBLE)**. Гэвч хүүхэд VOL+ товч дээр хуруугаа салгахгүй дарвал зурагтын дуу чангарч, буурах чагнагдахуйц чичиргээ (volume bouncing / flutter) үүснэ.
2. **Samsung Tizen (Local WebSocket) дээр:**  
   - Локал холболтоор дууны хувийг унших ямар ч API байхгүй тул 150ms-д хязгаарлах нь **ТЕХНИКИЙН ХУВЬД БОЛОМЖГҮЙ (UNREALISTIC)**.
3. **Samsung SmartThings Cloud дээр:**  
   - ТВ -> Samsung Cloud -> FamilyScreen Server -> Samsung Cloud -> ТВ гэсэн бүрэн тойрог нь дунджаар **1000–2500ms** авна. Энэ нь 150ms-ээс даруй 10 дахин удаан тул хүүхэд дууг хэт чангалаад хэдэн секунд үзэх боломжтой хэвээр байна.
4. **Манай FamilyScreen Android TV Box Agent дээр:**  
   - Зурагт дээрх Kotlin апп нь `AudioManager.STREAM_MUSIC`-ийг локал үйлдлийн системийн түвшинд сонсдог тул **1–5ms дотор (шуурхай)** хязгаарлаж чаддаг (**VERIFIED** 🟢).

### Дууны хяналтын 4 өөр түвшин:
- **Level 1: Remote Volume Adjustment (Алсын тохируулга):** Эцэг эх утаснаасаа дууг нэмэх, хасах, хаах (Mute) — *Бүх ТВ дээр 100% боломжтой*.
- **Level 2: Volume Monitoring (Дууны түвшинг харах):** Одоо ТВ дээр дуу ямар түвшинд байгааг харах — *LG webOS болон SmartThings дээр л боломжтой; Samsung Local болон Roku дээр боломжгүй*.
- **Level 3: Reactive Volume Cap (Хариу үйлдэлтэй хязгаарлалт):** Дуу өсөхөд сүлжээгээр буцааж татах — *Зөвхөн LG webOS дээр л локалаар боломжтой (Гэхдээ утас асаалттай эсвэл Gateway байх үед)*.
- **Level 4: Tamper-Resistant Volume Enforcement (Үл тойрох хатуу хязгаарлалт):** Хүүхэд пультээр яаж ч оролдоод дууг тогтоосон хязгаараас 1 хувь ч чангалах боломжгүй байх — *Зөвхөн төхөөрөмж дээрх FamilyScreen Agent (Android TV Box) дээр л боломжтой*.

## 5. Аюулгүй Байдал, Нууцлал ба Мобайл Хязгаарлалтууд

1. **Токен болон Нууц Түлхүүрийн Хадгалалт (Credential Storage):**
   - LG webOS-ийн `client-key` болон Samsung-ийн `token` нь тухайн айлын сүлжээний төхөөрөмжийг шууд удирдах эрхтэй тул өгөгдлийн санд **хэзээ ч plain-text хадгалж болохгүй**.
   - Backend дээр `AES-256-GCM` шифрлэлтээр хадгалах, гар утсанд зөвхөн `FlutterSecureStorage` (iOS Keychain / Android Keystore)-д хадгалах дүрэм мөрдөнө.
2. **Local Network Man-in-the-Middle (MITM) & Unauthenticated Access:**
   - webOS-ийн хуучин порт 3000 болон Samsung-ийн 8001 нь энгийн шифрлэлтгүй WebSocket ашигладаг тул нэг Wi-Fi сүлжээнд байгаа хэн ч пакет барьж авах эрсдэлтэй. Иймээс шинэ загваруудад заавал TLS порт 3001 (webOS) болон 8002 (Tizen)-ийг ашиглана.
3. **Мобайл Системийн Арын Горим (iOS/Android Background Kill):**
   - iOS дээр апп background-д шилжээд 30 секундын дараа систем WebSocket-ийг алдаг тул **"Гар утаснаасаа ямар ч сервер, gateway-гүйгээр хүүхдийн зурагтын дууг өдөржин сүлжээгээр хаана" гэж амлах нь архитектурын том алдаа болно**.
   - Үүнийг шийдэх 2 зам:
     - **Арга А (FamilyScreen Local Gateway):** Гэрийн компьютер (PC Dashboard), Android TV Box, эсвэл гэрийн чиглүүлэгч/сервер дээр арын сервис ажиллуулах.
     - **Арга Б (Agent Deployment):** ТВ дээр нь өөрт нь FamilyScreen Agent суулгах.

## 8. Зөвлөмжит MVP Платформ ба Хэрэгжүүлэлтийн Архитектур

### 8.1. Сүлжээний удирдлагыг эхлүүлэх MVP платформ: **LG webOS**
- **Шалтгаан:** LG webOS нь Smart TV-үүд дундаас цорын ганц **WebSocket-ээр дууны бодит хувийг уншиж, тааруулж, өөрчлөлтийг subscribe хийж болдог** нээлттэй локал протоколтой платформ юм.
- Түүнчлэн нэмэлт үүлэн данс (Samsung Account/PAT) шаардахгүйгээр зөвхөн орон нутгийн Wi-Fi сүлжээгээр шууд холбогддог тул хэрэглэгчийн туршлага (UX) хамгийн хялбар, үрэлтгүй байна.

### 8.2. Зөвлөмжит Системийн Загвар (Hybrid Gateway Model):
1. **Зөөврийн удирдлага (Handheld Remote):** Эцэг эхийн гар утасны Flutter апп нь шууд Wi-Fi-аар LG, Samsung, Android TV-ийн дууг нэмэх/хасах/хаах, асаах/унтраах универсал удирдлага болж ажиллана.
2. **Тасралтгүй хяналт ба Volume Cap:**
   - **Хувилбар 1 (ТВ хайрцагтай айлуудад):** FamilyScreen Android TV Box нь өөрөө гэрийн байнга асаалттай Gateway болж, өрөөний бусад LG зурагтуудын дууг тасралтгүй хянана.
   - **Хувилбар 2 (Компьютертэй айлуудад):** PC Web Dashboard / Background Service нь компьютероос ТВ-ийн дууны дээд хязгаарыг удирдан барина.
   - **Хувилбар 3 (Хүүхдийн өрөөний хатуу хяналтад):** FamilyScreen Android TV Box ашиглан 100% тойрч гарахгүй хатуу дүрмийг мөрдүүлнэ.

## 9. Дараагийн Шатны Хэрэгжүүлэлтийн Төлөвлөгөө (Phased Roadmap)

- **Phase 11.2 (Universal Device Architecture):** Олон төрлийн ТВ төхөөрөмжүүдийг нэгтгэн удирдах хийсвэр интерфэйс (`BaseTvAdapter`), өгөгдлийн сангийн шилжүүлэг, тушаалын ээлж (Command Queue) боловсруулах.
- **Phase 11.3 (Local Discovery & Pairing):** mDNS болон SSDP ашиглан гэрийн Wi-Fi дээрх ТВ-үүдийг автоматаар хайх, LG-ийн PIN баталгаажуулалтыг Flutter болон Backend дээр холбох.
- **Phase 11.4 (Volume & Power Control):** Дуу тохируулах, хаах, ТВ асаах/унтраах протоколын тушаалуудыг хэрэгжүүлэх.
- **Phase 11.5 (LG webOS Adapter):** LG webOS SSAP холболтыг бүрэн хэрэгжүүлж, турших.
- **Phase 11.6 (Samsung Tizen Adapter):** Samsung Tizen WebSocket удирдлага болон SmartThings холболтыг нэмэх.
- **Phase 11.7 (Android TV Remote Adapter):** Android TV Remote v2 протоколыг холбох.
- **Phase 11.8 (PC Web Dashboard):** Компьютерээс олон ТВ-г удирдах хяналтын самбарыг хөгжүүлэх.
- **Phase 11.9 (Integration & Security Audit):** Бүх платформ дээрх нэгдсэн шалгалт.
