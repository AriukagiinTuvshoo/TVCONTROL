## 3. Нарийвчилсан Шинжилгээ (Detailed Technical Analysis)

### 3.1. F-01 (CRITICAL): `Unknown` Төлөвийн Хамгаалалтын Цоорхой
- **Одоогийн кодын байдал:**
  `UsageEventStateMachine.kt` мөр 283–285:
  ```kotlin
  is ForegroundDetectionState.Unknown -> {
      // Fail-safe: do not blindly block when state is unknown, but do not bill usage either
      Pair(EnforcementDecision.AllowSystemOrIdle, null)
  }
  ```
- **Согогийн механизм:**
  1. `UsageMonitoringService` нь шийдвэр `AllowSystemOrIdle` байвал `bringLauncherToFront()`-ийг дууддаггүй.
  2. Төхөөрөмж асаад эхний 1–5 секундэд (cold start / boot), эсвэл Android 11+ төхөөрөмж түгжээтэй үед `queryEvents()` нь `null` эсвэл хоосон буцааж төлөв `Unknown("NO_EVENTS_YET")` болно.
  3. Хэрэв хүүхэд энэ хугацаанд хориотой апп (Chrome, Тоглоом) нээсэн бол уг апп дэлгэц дээр **ямар ч хориггүйгээр бүтэн ажиллана**. "Цаг тоолохгүй" байгаа нь хүүхдийг хориглож байгаа хэрэг биш, харин ч үнэгүй, хяналтгүй үзэх боломж олгож байна.
- **Санал болгож буй хамгаалалтын бодлого (Safe Holding Screen):**
  - Эхлэлтийн үед 3 секундын "Warm-up" хугацаа олгоно.
  - Хэрэв `Unknown` төлөв 3 секундээс дээш үргэлжилбэл дурын аппыг зөвшөөрөхгүй, харин **FamilyScreen Launcher руу шилжүүлж "Хяналтын системийг синхрончилж байна..." гэсэн түр барих (Safe Holding Screen)** горимд шилжүүлнэ.

### 3.2. F-02 (HIGH): IME Exemption-ийн Нэрийн Шүүлтүүрийн Эрсдэл
- **Одоогийн кодын байдал:**
  `UsageEventStateMachine.kt` мөр 96:
  ```kotlin
  if (packageName.contains(".inputmethod.") || packageName.endsWith(".ime")) return true
  ```
- **Согогийн механизм:**
  - Android-д дурын хөгжүүлэгч өөрийн аппын package нэрийг дураараа сонгож болно (жишээ нь `com.action.game.ime` эсвэл `com.tiktok.inputmethod.video`).
  - Энэхүү string pattern matching нь тухайн апп бодит систем эсвэл гар мөн эсэхийг огт шалгахгүйгээр `isSystemExempt() = true` буцаана.
  - Үүний улмаас хориотой апп уг нэрийн хэв маягийг ашиглан FamilyScreen-ийн бүх хязгаарлалтыг бүрэн тойрч гарах боломжтой.
- **Санал болгож буй засвар:**
  1. `contains(".inputmethod.")` болон `endsWith(".ime")` гэсэн таамагласан шүүлтүүрийг **бүрэн устгах**.
  2. Зөвхөн баталгаажсан системийн багцуудын жагсаалт (`DEFAULT_SYSTEM_EXEMPT_PACKAGES`)-аар хатуу шалгах.
  3. Төхөөрөмж дээр ажиллахдаа `context.packageManager.getApplicationInfo(pkg, 0).flags and ApplicationInfo.FLAG_SYSTEM != 0` нөхцөлөөр системийн жинхэнэ апп мөн эсэхийг шалгах.

### 3.3. F-03 (MEDIUM): System UI ба Volume Overlay-ийн Бодит Байдал
- **Байдал:** Phase 10.8-д `com.android.systemui`-ийг чөлөөлснөөр дууны цонх (volume panel) хаагдахаа больсон гэж тайлагнасан.
- **Бодит Android архитектур:**
  - Android TV-ийн Дууны тохируулга нь `WindowManager.LayoutParams.TYPE_VOLUME_OVERLAY` эсвэл `TYPE_SYSTEM_ALERT` төрлийн **Window Overlay** юм. Энэ нь бие даасан `Activity` биш тул `UsageEvents`-д `ACTIVITY_RESUMED` үүсгэдэггүй!
  - `com.android.systemui`-г Activity түвшинд чөлөөлсөн нь System UI-ийн бүрэн дэлгэцийн Activity (жишээ нь Quick Settings panel, Recents menu)-д хамаарахаас бус, хөвөгч overlay-д хамаарахгүй.
  - Иймд Volume Overlay-ийн бодит зан төлөвийг зөвхөн бодит ТВ Box дээр шалгаж байж баталгаажуулна.

## 4. Бодитоор Зөв Болсон Архитектурын Амжилтууд

Adversarial шалгалтаар дараах механизмууд үнэхээр зөв шийдэгдсэнийг батлав:
1. **Multi-Activity State Tracking:** Нэг багц дотор Activity шилжихэд багцыг бүхэлд нь ард орсонд тооцохгүй Set бүтэц нь зөв ажиллаж байна.
2. **Missing Pause Recovery:** Унасан (crash) апп `PAUSED` өгөөгүй ч дараагийн апп `RESUMED` болоход Primary Focus шилжиж байгаа нь зөв.
3. **Intent Loop Throttle:** 2000ms throttle guard нь давтан `startActivity` хийхээс найдвартай сэргийлж байна.
4. **`FamilyScreenLauncherActivity`-ийн `onNewIntent`:** `EXTRA_BLOCK_REASON` ба `EXTRA_BLOCKED_PACKAGE` зөв хүлээн авч үнэн зөв мэдээлэл харуулж байна.

## 6. Физик ТВ Box Дээр Заавал Шалгах Үлдсэн Асуудлууд

Дараах зүйлсийг цэвэр JVM тестээр батлах боломжгүй бөгөөд зөвхөн бодит техник дээр шалгана:
1. Төхөөрөмжийн Volume товч дарахад дэлгэц анивчих эсэх.
2. Төхөөрөмж түгжээтэй байхаас асах (Direct Boot) үеийн `queryEvents()` зан төлөв.
3. Хятад TV Box-ийн түрэмгий RAM цэвэрлэгч `UsageMonitoringService`-ийг унтраах эсэх.
4. Төхөөрөмж дээрх хориотой апп хаагдах бодит секундын хэмжилт.
