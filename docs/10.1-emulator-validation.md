## 2. Android TV Эмуляторын Орчин ба Тохиргоо

### 2.1. Зөвлөмжит Эмуляторын Үзүүлэлт (AVD Specification):
- **Төхөөрөмжийн профайл:** `tv_1080p` (1920x1080 Landscape, TV DPI)
- **Системийн Image:** `system-images;android-30;android-tv;x86_64` (Android TV API 30 Google TV/Leanback)
- **CPU Architecture:** `x86_64` (KVM acceleration-тай)
- **RAM санах ой:** 2048 MB
- **VM Heap:** 512 MB
- **Дотоод диск:** 4096 MB
- **Дэлгэцийн чиглэл:** `landscape` (хэвтээ, singleTask)

### 2.2. CI дээрх Эмуляторын Ажиллагаа (`.github/workflows/android_tv_emulator.yml`):
- GitHub Actions дээр KVM (`/dev/kvm`) виртуалчлалыг идэвхжүүлж `reactivecircus/android-emulator-runner@v2` ашигласан тусгай эмуляторын workflow бэлтгэв.
- Эмулятор асмагц:
  1. `adb wait-for-device` хийж OS хувилбар болон төхөөрөмжийн загварыг уншина.
  2. `app-debug.apk`-г автоматаар суулгана (`adb install -r`).
  3. `PACKAGE_USAGE_STATS` болон `SYSTEM_ALERT_WINDOW` эрхүүдийг ADB-ээр олгоно.
  4. `FamilyScreenLauncherActivity`-г `EXTRA_BACKEND_URL` тохиргоотойгоор асаана.
  5. `dumpsys window` ашиглан дэлгэцийн фокус болон foreground Activity-г шалгана.
  6. D-Pad товчлуурын коммандуудыг (`adb shell input keyevent 23` [DPAD_CENTER], `22` [DPAD_RIGHT])-ийг илгээнэ.

### 2.3. Локал Эмулятор Үүсгэж Ажиллуулах Заавар (Local AVD Runbook):
```bash
# 1. Android TV system image татах:
sdkmanager "system-images;android-30;android-tv;x86_64"

# 2. AVD үүсгэх:
avdmanager create avd -n "FamilyScreen_TV_API30" \
  -k "system-images;android-30;android-tv;x86_64" \
  -d "tv_1080p"

# 3. Эмуляторыг эхлүүлэх:
emulator -avd FamilyScreen_TV_API30 -no-audio -gpu host

# 4. APK суулгах ба эхлүүлэх:
adb install -r android_tv_box/app/build/outputs/apk/debug/app-debug.apk
adb shell am start -n mn.familyscreen.tv/.ui.FamilyScreenLauncherActivity
```

## 3. Автомат Тестийн Нарийвчилсан Бүтэц (34 Тест)

Өмнөх Phase 10-ын 8 тестийг давхардуулахгүйгээр шинэ 26 автомат тест нэмж, нийт **34 автомат тест** бүрдүүлэв:

### 3.1. `LocalTimeEngineTest` (Анхны 8 суурь тест):
1. Whitelisted апп foreground-д байх үед л цаг тоолох (Launcher/Standby үед 0 сек)
2. Цаг ухраах оролдлогоос хамгаалагдсан monotonic clock
3. Шөнө дундын огноо шилжилт (Midnight rollover)
4. 72 цаг оффлайн болоход автоматаар BLOCK болох
5. PBKDF2 болон SHA-256 hash дэмжлэг
6. 5 удаа буруу PIN оруулахад 15 минут түгжих ба reboot хийхэд хадгалагдах
7. 15, 5, 1 минутын анхааруулгын босго
8. Тохируулаагүй хоосон PIN-ээр нэвтрэх оролдлогыг татгалзах

### 3.2. `LocalTimeEngineExtendedTest` (Шинэ 10 тест):
1. **Ажлын өдрийн лимит тооцоолол:** Даваа-Баасан гарагт weekend bonus нэмэгдэхгүй үндсэн лимит мөрдөгдөх.
2. **Амралтын өдрийн лимит:** Бямба, Ням гарагт `weekendBonusSeconds` автоматаар нэмэгдэх (90 мин + 30 мин = 120 мин).
3. **Хуваарийн гадуурх хаалт:** Daily limit-ээс цаг үлдсэн байсан ч зөвшөөрөгдсөн цагийн хуваарийн гадуур (жишээ нь 22:30) шууд BLOCK төлөвт шилжих.
4. **Parent Instant Lock давуу эрх:** Эцэг эх гар утаснаас Instant Lock хийсэн үед хуваарь болон үлдсэн цагаас үл хамааран шууд BLOCK болох.
5. **Whitelist хатуу шалгалт:** Жагсаалтад байхгүй болон `isAllowed=false` тохиргоотой аппуудыг татгалзах.
6. **Whitelist түр унтраах горим:** `enforceWhitelist=false` үед бусад аппыг зөвшөөрөх.
7. **Хэрэглээний цаг хорогдох шат дараалал:** 10 минут, 15 минутаар хорогдож 5 минутын сэрэмжлүүлэг рүү үсрэх.
8. **PIN override-аар BLOCK-оос гаргах:** Хугацаа дууссан үед PIN оруулж +15 минут нэмэхэд шууд сэргэх.
9. **Буруу сунгалтын хугацааг татгалзах:** Зөвхөн 5, 10, 15, 30, 60 минутын сунгалтыг зөвшөөрөх (бусад утга 0 үлдэнэ).
10. **15 минутын түгжээ дуусах мөч:** 14 минутад зөв PIN байсан ч татгалзах ба 15 мин + 1 секундэд амжилттай нээгдэх.

### 3.3. `TvBackendClientContractsTest` (Шинэ 6 тест):
1. **Base URL хэлбэржүүлэлт:** Зай болон сүүлийн `/`-ийг цэвэрлэх (`http://192.168.1.15:8000`).
2. **Pairing Init JSON гэрээ:** `hardware_uid`, `device_type`, `device_name`, `app_version` талбаруудын бүтэц.
3. **PIN Override JSON гэрээ:** `source="TV_PIN"`, `pin_code`, `added_minutes`, `reason` талбаруудын бүтэц.
4. **Usage Session JSON гэрээ:** `client_session_uid`, `active_seconds`, `synced_from_offline` талбарууд.
5. **Policy Sync JSON задлагч:** Backend-ийн бодлого, апп жагсаалт, хуваариудыг бүрэн алдаагүй загвар болгох.
6. **Exponential Backoff дараалал:** 300ms, 600ms, 1200ms зөв тооцоологдох.

### 3.4. `TvOfflineStateAndPersistenceTest` (Шинэ 5 тест):
1. **Snapshot JSON бүтэн байдал:** Бүх талбаруудыг JSON болгож буцаан задлахад өгөгдөл гээгдэхгүй байх.
2. **Reboot Anti-Tamper Anchor:** Reboot хийхэд цаг ухрахаас сэргийлж `maxOf(serverSyncTime, lastTrustedUtcMs)` ашиглах.
3. **Client Session UID үүсэлт:** `tv-sess-` угтвартай давтагдашгүй UUID хэлбэр.
4. **72 цагийн оффлайн босго:** 259,200,000 миллисекундийн нарийвчлалтай тооцоолол.
5. **PIN Lockout хугацааны тооцоолол:** Одоогийн цаг дээр яг 900,000 мс (+15 мин) нэмэх.

### 3.5. `AndroidTvKeyAndNavigationLogicTest` (Шинэ 5 тест):
1. **D-Pad товчны код тохироо:** DPAD_CENTER (23), DPAD_UP (19), DPAD_DOWN (20), DPAD_LEFT (21), DPAD_RIGHT (22), BACK (4).
2. **BACK товчны хамгаалалт:** BLOCK төлөвт BACK товчийг хаах (`return true`), ALLOW төлөвт нэвтрүүлэх (`return false`).
3. **Серверийн хаяг ба PIN код ялгах:** `http://` эсвэл `https://`-ээр эхэлсэн текстийг серверийн хаяг гэж таних, тоон 4 оронтойг PIN гэж ялгах.
4. **Boot Receiver эвент шүүлтүүр:** `BOOT_COMPLETED` болон `MY_PACKAGE_REPLACED` үйлдлүүдийг зөв таних.
