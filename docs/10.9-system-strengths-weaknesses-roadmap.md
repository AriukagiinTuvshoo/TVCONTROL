# Phase 10.9 — FamilyScreen Архитектурын Гүнзгий Аудит: Давуу Тал, Сул Тал ба Замын Зураг

**Төсөл:** FamilyScreen TV Monitoring System  
**Огноо:** 2026-11-10  
**Салбар:** `test/phase10-android-tv-box-validation`  
**Хамрах хүрээ:** Android TV Box, Cloud Backend, Mobile Parent App, Тест ба Аюулгүй байдал.

---

## 1. Хураангуй (Executive Summary)

Сүүлийн үеийн хөгжүүлэлтээр бид системийн аюулгүй байдал, төлөвийн машин (`UsageEventStateMachine`), монотон цаг тоолуур (`LocalTimeEngine`), JWT хамгаалалт, офлайн синк зэрэг суурь архитектурыг өндөр түвшинд хүргэж, нийт **39 Android нэгж тест**, **42 Backend pytest**, 3 бие даасан CI pipeline-ийг 100% ногоон болголоо.

Гэвч аливаа системийг үйлдвэрлэлд (Production) нэвтрүүлэхэд давуу талуудаас гадна бодит орчинд тулгарах сул тал, эрсдэлүүдийг бодитоор дүгнэх шаардлагатай.

---

## 2. Системийн Бодит ДАВУУ ТАЛУУД (Architectural Strengths)

1. **Цэвэр Төлөвийн Машин (Pure Kotlin State Machine):**
   - Android UI болон Emulator-оос 100% салангид тул стандарт JVM дээр миллисекундын дотор бүтэн тестлэгддэг.
   - Олон Activity-тай аппуудыг ард орсон гэж андуурдаггүй, давхардсан үйл явдлыг 500 түүхээр найдвартай шүүдэг.
2. **Монотон Цагийн Хамгаалалт (Monotonic Time Engine):**
   - ТВ-ийн системийн огноо, цагийг хүүхэд гараар өөрчилсөн ч дэлгэцийн цагт нөлөөлөхгүй (`SystemClock.elapsedRealtime()`).
   - 72 цагийн офлайн хязгаарлалт болон шөнө дундын 00:00 цагийн Midnight rollover-ийг алдаагүй тооцдог.
3. **Идемпотент Офлайн Синк (Idempotent Offline-First Data Layer):**
   - `client_session_uid` ашиглан сүлжээ тасрах, дахин нийлүүлэх үед өгөгдөл сервэрт давхардаж цаг хорогдуулахаас 100% сэргийлсэн.
4. **Хатуу Шүүлтүүртэй Аюулгүй Байдал (Hardened Defense):**
   - IME wildcard нэрээр хуурч хориотой апп ажиллуулах цоорхойг (F-02) хаасан.
   - 5 секундийн хүлээлтийн хугацаа хэтэрвэл `HOLDING_UNKNOWN_STATE` горимд шилжүүлж хориотой аппыг далд ажиллуулахаас сэргийлсэн (F-01).
   - RS256/HS256 Dual JWT болон Supabase Account Takeover-оос сэргийлсэн хамгаалалттай.
5. **ТВ Боксын Хөнгөн Сүлжээний Давхарга:**
   - Хүнд гуравдагч талын сангуудаас татгалзаж, эх `HttpURLConnection` ашигласнаар RAM багатай хайрцгууд дээр ачаалал хамгийн бага.

## 3. Системийн БОДИТ СУЛ ТАЛУУД БА НУУГДМАЛ ЭРСДЭЛҮҮД (Weaknesses & Risks)

| Эрсдэл | Түвшин | Шалтгаан ба Бодит Үр Дагавар |
| :--- | :---: | :--- |
| **0.5–1.5s Дэлгэцийн Завсар (Visual Exposure Delay)** | **ӨНДӨР** | 1 секундийн polling loop ажилладаг тул хүүхэд хориотой апп дээр дарахад уг апп дэлгэц дээр 500ms–1500ms харагдаж байгаад хаагддаг. Зарим хямд ТВ бокс үйл явдлыг 2–5 секундээр batch хийж нийлүүлбэл энэ хугацаа уртасна. |
| **Android 10+ Background Start Хязгаарлалт** | **ӨНДӨР** | Хэрэв эцэг эх FamilyScreen-ийг ТВ-ийн "Default Home Launcher" болгож сонгоогүй бол `UsageMonitoringService` ардаас `startActivity()` дуудахад үйлдлийн систем цонх урд гаргахыг хориглож гацна. |
| **Хямд ТВ Боксын Low Memory Killer (LMK)** | **ӨНДӨР** | 1GB/2GB RAM-тай хямд ТВ хайрцгууд арын процессуудыг маш түрэмгийгээр устгадаг. Foreground Service байсан ч систем устгаж болзошгүй бөгөөд үйлчилгээ унтвал хүүхэд хяналтгүй үзэх эрсдэлтэй. |
| **Real-time Push Байхгүй (30s Саатал)** | **ДУНД** | ТВ Бокс нь сервэрийг 30 секунд тутамд poll хийдэг тул гар утаснаас "ТВ-ийг Одоо Түгжих" дарахад ТВ дээр 30 секунд хүртэл хугацааны дараа түгжигдэнэ. Энэ нь хэрэглэгчид "систем ажиллахгүй байна" гэж мэдрэгдэнэ. |
| **ТВ удирдлагын (D-Pad) Фокус Алдагдах** | **ДУНД** | Launcher UI нь энгийн `LinearLayout`-ээр хийгдсэн тул `androidx.leanback` шиг ТВ-ийн удирдлагад зориулсан фокус менежмент дутмаг, удирдлагын сум дарахад товч харагдахгүй алдагдах магадлалтай. |

## 4. Засах ба Сайжруулах Бодит Замын Зураг (Actionable Roadmap)

### Алхам 1: Phase 10.9 (Pre-Hardware Quick Wins)
1. **Adaptive Polling (250ms–300ms):**
   - Хөдөлгөөн илэрсэн агшинд polling интервалыг 300ms болгон хурдасгаж, хориотой аппын дэлгэцэд харагдах хугацааг 300ms хүртэл бууруулах.
2. **Default Home Launcher Setup Wizard:**
   - ТВ Бокс анх асах үед FamilyScreen нь Default Launcher мөн эсэхийг шалгаж, биш бол эцэг эхээр заавал тохируулуулах цонх гаргаж Background Start хязгаарлалтыг хаах.
3. **Real-Time Push (SSE / WebSocket):**
   - 30 секундийн хүлээн суух саатлыг арилгаж, гар утаснаас Instant Lock хийхэд **1 секундийн дотор** ТВ Бокст тушаал хүрдэг болгох.

### Алхам 2: Тогтвортой Байдал ба Hardware Нийцэл
1. **Dual-Process Watchdog:**
   - Үндсэн мониторинг процесс санах ойн хомсдолоос болж алагдвал түүнийг 1 секундийн дотор дахин сэргээдэг жижиг туслах процесс нэмэх.
2. **Leanback Focus UI сайжруулалт:**
   - Товчлууруудад D-Pad фокусын шар хүрээ, 1.1x томордог эффект оруулж хэрэглэгчийн туршлагыг өсгөх.

### Алхам 3: Тусгай Төхөөрөмж (Dedicated SKU)
- Хэрэв ирээдүйд бэлэн FamilyScreen Box борлуулахаар шийдвэл ROM-д нь `Device Owner` эрхийг урьдчилан суулгаж, 0 секундийн бүрэн Kiosk горимоор шийдэх.
