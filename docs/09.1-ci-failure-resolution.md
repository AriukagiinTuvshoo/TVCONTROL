## 2. Суурь шалтгааны шинжилгээ ба хэрэгжүүлсэн шийдлүүд

### 2.1. Backend CI (`NoSuchTableError: users`)

#### Илэрсэн алдаа:
`sqlalchemy.exc.NoSuchTableError: users` нь модуль импортлох үед `backend/app/migrations.py` дотор `inspector.get_columns("users")` дуудагдах үед шинэ хоосон өгөгдлийн санд `users` хүснэгт хараахан үүсээгүй байснаас үүссэн.

#### Хэрэгжүүлсэн шийдэл:
1. **Schema Check Guard:** `_migration_001_upgrade` ба `_migration_001_downgrade` функцүүдэд `if not inspector.has_table("users"): return` шалгалтыг нэмсэн.
2. **Lifecycle Initializer (`init_db`):** Модуль импортлох үед шууд шилжүүлэг дууддаг аюултай бүтцийг халж, `init_db(engine)` функцээр `Base.metadata.create_all(bind=engine)`-ийг эхлээд ажиллуулж baseline үүсгэсний дараа `run_migrations(engine)`-ийг эрсдэлгүй ажиллуулдаг болгосон.
3. **Concurrent JIT Provisioning Retry:** Supabase хэрэглэгч анх удаа нэгэн зэрэг олон хүсэлтээр хандах үед үүсэх `IntegrityError`-ийг 50ms-ийн завсартай 5 удаагийн micro-retry хийж, түрүүлж commit хийсэн өгөгдлийг алдаагүй татаж авдаг хамгаалалт нэмсэн.
4. **Нэмэлт тестүүд:** `backend/tests/test_concurrency_and_migrations.py` файлд:
   - `test_empty_database_initialization`
   - `test_existing_database_upgrade`
   - `test_repeated_migration_execution_is_idempotent`
   - `test_migration_failure_and_recovery`
   зэрэг 4 шинэ тест нэмж, нийт **38/38 тест** бүрэн амжилттай болсон.

### 2.2. Android TV Box CI

#### Илэрсэн алдаанууд:
1. `Could not find or load main class org.gradle.wrapper.GradleWrapperMain`: `gradlew` Unix wrapper скриптэд `APP_HOME` тодорхойлогдоогүй хоосон байснаас Java classpath `/gradle/wrapper/gradle-wrapper.jar` (root)-ээс хайж олдоогүй.
2. `Execution failed for task ':app:checkReleaseAarMetadata' > Configuration ':app:releaseRuntimeClasspath' contains AndroidX dependencies, but the 'android.useAndroidX' property is not enabled`: AGP 8.3-д `android_tv_box/gradle.properties` байхгүй байсан тул AndroidX хамаарлуудыг блоклосон.
3. `Unresolved reference: somesalt`: `LocalTimeEngineTest.kt`-д `val pbkdf2Hash = "pbkdf2_sha256$200000$somesalt$..."` бичигдсэн нь Kotlin string interpolation-д хувьсагч гэж танигдаж компиляцийн алдаа заасан.
4. `LocalTimeEngineTest > pin brute force locks out after 5 failed attempts`: Failed attempt-ууд `10_000L` дээр гарч байхад тест 15 минутын дараах шалгалтыг `1_000L + 15min + 1sec` гэж 9 секунд дутуу тооцоолсноос lockout хугацаа дуусаагүй байхад шалгаж унасан.

#### Хэрэгжүүлсэн шийдэл:
1. **Official POSIX Gradle Wrapper:** `android_tv_box/gradlew` файлыг symlink тайлагч `cd -P` бүхий албан ёсны Gradle 8.4 wrapper-аар сольж, `chmod +x` эрх олгосон.
2. **`gradle.properties` үүсгэсэн:**
   ```properties
   android.useAndroidX=true
   android.nonTransitiveRClass=true
   org.gradle.jvmargs=-Xmx2048m -Dfile.encoding=UTF-8
   ```
3. **Android SDK Setup Action сайжруулалт:** `.github/workflows/android_tv_box.yml` дээр `android-actions/setup-android@v4` ашиглан `platforms;android-34 build-tools;34.0.0 platform-tools`-ийг тодорхой бэлтгэсэн.
4. **Kotlin String Interpolation ба PBKDF2 тест:** `LocalTimeEngineTest.kt`-д `\$` тэмдэгтийг зөв escape хийж, бодит `PBKDF2WithHmacSHA256` түлхүүр үүсгэлтийг шалгадаг болгов.
5. **Lockout Timing Calibration:** Failed attempts-ийг anchor `1_000L` хугацаанд тооцож, 15 минутын дараах түгжээ тайлагдалтыг секундийн нарийвчлалтай нийцүүлснээр **8/8 unit test** амжилттай болсон.
6. **Artifact Build:** `assembleDebug` болон `assembleRelease` зэрэг ажиллаж `FamilyScreen-AndroidTV-APK` (5.1MB) татагдах боломжтой болсон.

### 2.3. Mobile Flutter CI

#### Илэрсэн алдаанууд:
1. `CardTheme` type mismatch: Flutter 3.22+-д `ThemeData.cardTheme` нь `CardThemeData?` төрөл шаарддаг.
2. `Expected a declaration, but got '}'`: `_PinSetupScreenState` ангийн төгсгөлд нэмэлт хаалт үлдсэн байсан.
3. Registration `pinCode` nullable mismatch: `apiClient.register` функц non-nullable `String pinCode` шаарддаг байхад `String?` дамжуулсан.
4. `value is deprecated, use initialValue`: Flutter 3.33-д `DropdownButtonFormField.value` нь deprecate болсон.
5. `withOpacity is deprecated, use withValues()`: Өнгөний тунгалагшил тооцоололд `withValues(alpha: 0.12)` шаардсан.
6. `A RenderFlex overflowed by ... pixels on the bottom`: Test default viewport нь 800x600 байсан тул утасны дэлгэц overflow хийсэн.
7. `Actual: _TextWidgetFinder:<Found 0 widgets with text "Энэрэл": []>`: UI дээр хүүхдийн нэр `'Энэрэл (7-9)'` болон `'Энэрэл-ийн өнөөдрийн төлөв'` хэлбэрээр байдаг тул `find.text('Энэрэл')` exact match олоогүй.

#### Хэрэгжүүлсэн шийдэл:
1. `CardThemeData` руу бүрэн хөрвүүлсэн.
2. Илүүц хаалтыг хасаж цэвэрлэсэн.
3. Бүртгэлийн үед 4-6 оронтой тоон PIN шалгалтыг хийж non-nullable `String` дамжуулсан.
4. `value:`-ийг `initialValue:` болгон сольсон.
5. `color.withOpacity(0.12)`-ийг `color.withValues(alpha: 0.12)` болгон шинэчилсэн.
6. `mobile_app/analysis_options.yaml` стандартыг `package:flutter_lints/flutter.yaml`-тай нийцүүлж, шинжилгээг 0 info, 0 warning, 0 error болгосон.
7. `mobile_app/test/widget_test.dart`-д тест бүрийн эхэнд `tester.view.physicalSize = const Size(1080, 2400)` болон `devicePixelRatio = 1.0` тохируулж, offscreen товч дарахаас сэргийлж `ensureVisible` нэмсэн.
8. Хүүхдийн нэрийн шалгалтыг `find.textContaining('Энэрэл')` болгосноор **2/2 интеграцийн тест** 100% амжилттай давсан.
