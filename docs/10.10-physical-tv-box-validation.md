## 2. Төхөөрөмж Илрүүлэх ба ADB Протокол (Device Discovery)

Төхөөрөмжийн чипсет (Amlogic, Rockchip, Allwinner г.м)-ийг урьдчилан таамаглахгүйгээр дараах хоёр горимоор найдвартай холбогдох оношилгооны горимыг бэлтгэв.

### 2.1. Холболтын заавар
1. **USB ADB горим:**
   - TV Box-ийн `Developer options -> USB debugging`-ийг идэвхжүүлнэ.
   - Компьютерт USB кабелиар холбож `adb devices -l` командаар шалгана.
2. **Wi-Fi ADB горим (Кабельгүй үед):**
   - TV Box болон Компьютер нэг дотоод Wi-Fi сүлжээнд холбогдсон байх.
   - TV Box-ийн IP хаягийг тодорхойлно (жишээ нь `192.168.1.150`).
   - Команд: `adb connect 192.168.1.150:5555`

### 2.2. Төхөөрөмжийн Мета Өгөгдөл Цуглуулах Скрипт
Төхөөрөмж холбогдсон үед системийн мэдээллийг автоматаар унших коммандууд:
```bash
# 1. Android хувилбар болон API Level
adb shell getprop ro.build.version.release
adb shell getprop ro.build.version.sdk

# 2. Үйлдвэрлэгч ба Модель
adb shell getprop ro.product.manufacturer
adb shell getprop ro.product.model

# 3. Build Fingerprint
adb shell getprop ro.build.fingerprint

# 4. CPU архитектур
adb shell getprop ro.product.cpu.abi

# 5. Боломжит Санах ой (RAM)
adb shell cat /proc/meminfo | grep MemTotal

# 6. Дэлгэцийн нарийвчлал ба нягтрал
adb shell wm size
adb shell wm density

# 7. FamilyScreen багцын хувилбар
adb shell dumpsys package mn.familyscreen.tv | grep versionName

# 8. Usage Access эрхийн төлөв
adb shell appops get mn.familyscreen.tv GET_USAGE_STATS

# 9. Суурь үйлчилгээний төлөв (Foreground Service)
adb shell dumpsys activity services mn.familyscreen.tv
```

> [!CAUTION]
> Хэрэглэгчийн зөвшөөрөлгүйгээр төхөөрөмжийн аюулгүй байдлын тохиргоог алсаас өөрчлөхгүй, factory reset хийхгүй.

## 4. Хаалтын Саатал Хэмжих Арга Зүй (Enforcement Latency Profiling)

Бодит ТВ Бокс дээр хаалтын хугацааг 4 тусдаа үе шатаар хэмжих бөгөөд 300ms гэх мэт баталгаагүй тоог зарлахгүй:

$$\text{Total Exposure Time} = T_1 (\text{Event Delivery}) + T_2 (\text{SM Evaluation}) + T_3 (\text{Activity Takeover})$$

* **$T_1$:** Хэрэглэгч апп нээхээс Android OS-ийн `UsageEvents`-д `ACTIVITY_RESUMED` бүртгэгдэх хүртэлх саатал.
* **$T_2$:** Төлөвийн машин `UsageEventStateMachine`-аас `EnforceBlock` шийдвэр гаргах хүртэлх саатал ($< 5\text{ms}$).
* **$T_3$:** `startActivity(FamilyScreenLauncherActivity)` дуудагдаж цонх урд гарч бүтэн зурагдах хүртэлх хугацаа.

### Хэмжилтийн Статистик (Бодит төхөөрөмж холбогдсон үед 20 удаагийн дунджаар тооцно):

## 5. Аюулгүй Байдал ба Сэргэх Найдвартай Байдал (Safety Guarantees)

1. **Launcher Relaunch Loop үүсэхгүй:**
   `EnforceBlock` нь 2000ms, `EnforceHoldingScreen` нь 5000ms throttle-тэй тул системийг гацаах intent loop үүсэхгүй.
2. **Holding Screen-д гацахгүй:**
   Найдвартай үйл явдал илэрмэгц `CLEAR_HOLDING` тушаалаар хэвийн төлөв рүү шилжинэ.
3. **Usage Access байхгүй үед далд үзэх боломжгүй:**
   Эрх олгогдоогүй үед шууд `RequestPermission` цонх харагдана.
4. **Системийн хэрэгслүүдийг хаахгүй:**
   Дууны түвшин, гар, тохиргооны багцууд цагаан жагсаалтаар хамгаалагдсан.
5. **Төхөөрөмжийг эвдэхгүй:**
   Factory reset болон эрсдэлтэй систем бодлого оруулахгүй.
