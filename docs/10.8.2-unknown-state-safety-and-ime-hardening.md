## 1. Хураангуй (Executive Summary)

Phase 10.8.1 өрсөлдөгч (adversarial) аудитаар илрүүлсэн хоёр гол хамгаалалтын согог болох **F-01 (Critical)** болон **F-02 (High)**-ийг Phase 10.8.2-оор архитектурын түвшинд бүрэн шийдвэрлэж, кодын баталгаажуулалтыг амжилттай гүйцэтгэлээ:

1. **F-01 Засвар (Critical — Unknown State Infinite Bypass):**
   - Өмнөх шийдэлд `ForegroundDetectionState.Unknown` төлөвт систем хязгааргүй хугацаанд `AllowSystemOrIdle` горимд байж, хориотой апп далд ажиллах боломжтой байсныг засварлав.
   - Монотон цагт (`SystemClock.elapsedRealtime()`) суурилсан **5 секундийн хязгаарлагдмал хүлээлтийн хугацаа (bounded grace period)** нэвтрүүлэв (`unknownGracePeriodMs = 5000L`).
   - Хүлээлтийн хугацаанд ($< 5\text{s}$) дэлгэцийн цаг гүйлгэхгүй (`billing = null`), харин хугацаа хэтэрвэл ($\ge 5\text{s}$) `EnforcementDecision.EnforceHoldingScreen` шийдвэр үүсгэж, Launcher-ийг урд гарган дараах сануулгыг харуулна:
     > *"Хяналтын системийг эхлүүлж байна. Түр хүлээнэ үү..."*
   - Holding screen дуудах давтамжийг тусад нь `holdingThrottleWindowMs = 5000L`-ээр хязгаарлаж, хориотой аппын 2 секундийн throttle-тэй холилдохгүй байхаар тусгаарлав.
   - Бодит найдвартай төлөв сэргэхэд (`KnownForeground`), holding төлөв автоматаар цуцлагдана (`CLEAR_HOLDING`).

2. **F-02 Засвар (High — IME Substring Spoofing):**
   - Package нэрэнд таамаглал дэвшүүлж байсан `.contains(".inputmethod.")` болон `.endsWith(".ime")` wildcard нөхцөлүүдийг **бүрэн устгав**.
   - Зөвхөн баталгаажсан системийн тодорхой жагсаалт (`DEFAULT_SYSTEM_EXEMPT_PACKAGES`) болон аппын өөрийн багцыг зөвшөөрөх хатуу шалгалтаар солив.
   - Тусгай төхөөрөмж үйлдвэрлэгчийн (OEM) гараар өргөтгөх боломжийг `UsageEventStateMachine(systemExemptPackages = ...)` бүтцээр нээлттэй үлдээв.

3. **Тестийн тооллогын бодит залруулга ба өргөтгөл:**
   - Өмнөх Phase 10.8 тайлан дахь техникийн алдааг (34 тест гэж тооцоолсон нь бодит байдал дээр `setUp()` функц тоологдсоноос болж 32 байсан) албан ёсоор залруулав.
   - Phase 10.8.2-ын шинэ 7 тест нэмэгдсэнээр Android TV Box нэгж тестийн тоо **32-оос 39 тест** болж нэмэгдэв.

### 2.1. EnforcementDecision.EnforceHoldingScreen шинэ шийдвэр

```kotlin
sealed class EnforcementDecision {
    data class AllowActiveContent(val packageName: String) : EnforcementDecision()
    object AllowSystemOrIdle : EnforcementDecision()
    data class EnforceBlock(
        val reason: String,
        val blockedPackage: String?,
        val shouldTriggerLaunch: Boolean
    ) : EnforcementDecision()

    /**
     * Holding screen when foreground detection state remains Unknown past grace period.
     * Prevents unapproved apps from running indefinitely under unresolvable detection.
     */
    data class EnforceHoldingScreen(
        val reason: String = "HOLDING_UNKNOWN_STATE",
        val shouldTriggerLaunch: Boolean
    ) : EnforcementDecision()

    data class RequestPermission(val reason: String) : EnforcementDecision()
}
```

### 2.2. evaluateEnforcement logic & Monotonic Grace Period
```kotlin
            is ForegroundDetectionState.Unknown -> {
                val start = unknownSinceElapsedMs ?: nowElapsedMs
                val elapsedInUnknown = nowElapsedMs - start
                if (elapsedInUnknown < unknownGracePeriodMs) {
                    // Fail-safe grace period: do not block during brief event latency, but NEVER bill usage
                    Pair(EnforcementDecision.AllowSystemOrIdle, null)
                } else {
                    // Grace period exceeded: enforce holding screen to prevent unapproved apps from running indefinitely
                    val isThrottled = (nowElapsedMs - lastHoldingLaunchedMs) < holdingThrottleWindowMs
                    Pair(
                        EnforcementDecision.EnforceHoldingScreen(
                            reason = "HOLDING_UNKNOWN_STATE",
                            shouldTriggerLaunch = !isThrottled
                        ),
                        null
                    )
                }
            }
```

### 2.3. Хатуу Системийн Багцын Шалгалт (F-02)
Wildcard нөхцөлүүдийг хасаж, цэвэр O(1) Set lookup хийдэг болгов:
```kotlin
    fun isSystemExempt(packageName: String): Boolean {
        if (packageName.isBlank()) return false
        if (packageName == ownPackageName) return true
        return systemExemptPackages.contains(packageName)
    }
```
